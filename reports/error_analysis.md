# Error analysis

This report is generated by `python src/train.py` from the held-out test split.
It contains aggregate statistics only. Raw prompts are intentionally not committed
because the source data may contain unsafe or sensitive text.

## Summary

- Held-out examples: 409
- Misclassified examples: 72
- Error rate: 0.176

| Error type | Count | Median prompt length (chars) | Mean jailbreak score |
|---|---:|---:|---:|
| False negatives | 46 | 729.5 | 0.322 |
| False positives | 26 | 2641.5 | 0.751 |

## Interpretation

This baseline uses surface-form TF-IDF features from isolated prompts. It cannot
reliably infer intent or use conversation context. Inspecting raw errors locally can
help form hypotheses, but those hypotheses should be tested on a separate dataset
before they are presented as general findings.

## Reproduce

```bash
python src/download_data.py
python src/data_prep.py
python src/train.py
```

The same run also writes machine-readable metrics to `reports/metrics.json` and
confusion matrices to `reports/figures/`.
